# Course Hider - Мосполитех

Браузерное расширение (Chrome / Chromium) для управления отображением курсов в личном кабинете Московского Политеха ([online.mospolytech.ru](https://online.mospolytech.ru/my/courses.php)).

## Возможности
- **Группы курсов**: создание пользовательских групп (например, «1 курс», «2 курс», «Важные»).
- **Быстрый поиск**: поиск по курсам как в общем списке, так и при добавлении в группу.
- **Выпадающий список фильтрации**: быстрый выбор отображаемой группы (остальные курсы скрываются автоматически).
- **Скрытие ненужных курсов**: скрытие отдельных курсов без вмешательства в разметку страниц.
- **Чистый интерфейс**: всё настраивается внутри окна расширения, на страницы сайта не внедряются лишние кнопки.

## Установка
1. Откройте страницу chrome://extensions/ в браузере.
2. Включите **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
4. Перейдите на страницу курсов Мосполитеха и управляйте отображением через иконку расширения.
