# Privacy Policy / Политика конфиденциальности

Last updated: September 2026 / Последнее обновление: Сентябрь 2026

## English

**Course Hider - Мосполитех** is an open-source browser extension designed to help students organize, group, and hide courses on the Moscow Polytech LMS (online.mospolytech.ru and lms.mospolytech.ru).

### 1. Data Collection and Usage
- **No Personal Data Collected**: The extension does **not** collect, store, transmit, or share any personal information, login credentials, browsing history, or user analytics.
- **Local Storage Only**: All user configurations (such as created course groups and hidden course lists) are stored exclusively on the user's device using Chrome's local storage API (chrome.storage.local).
- **No Third-Party Communication**: The extension does not communicate with any external servers, third-party analytics services, or tracking tools.
- **Permissions**:
  - storage: Required solely to save course groups and visibility preferences locally on your machine.
  - activeTab: Used solely to detect course names and IDs on the currently opened Moscow Polytech course page.

### 2. Contact
If you have any questions about this Privacy Policy, you can open an issue on GitHub.

## Русский

**Course Hider - Мосполитех** — это браузерное расширение с открытым исходным кодом для организации, группировки и скрытия курсов в личном кабинете СДО Московского Политеха (online.mospolytech.ru и lms.mospolytech.ru).

### 1. Сбор и использование данных
- **Никаких персональных данных не собирается**: Расширение **не** собирает, не передает и не хранит личные данные, пароли, историю браузера или аналитику.
- **Исключительно локальное хранение**: Все пользовательские настройки (список групп курсов, перечень скрытых дисциплин) сохраняются только на вашем устройстве с помощью локального хранилища браузера (chrome.storage.local).
- **Отсутствие внешних запросов**: Расширение не отправляет никаких сетевых запросов на сторонние серверы, трекеры или сервисы сбора статистики.
- **Разрешения**:
  - storage: необходимо исключительно для сохранения ваших групп и настроек видимости на компьютере.
  - ctiveTab: используется исключительно для чтения списка курсов на активной вкладке сайта Мосполитеха.
